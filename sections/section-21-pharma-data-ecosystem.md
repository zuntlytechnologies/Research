# Section 21 — Pharma Data Ecosystem

> **Input from all prior:** every function emits data, mostly trapped. **This section's job:** map the data estate and find **data-network, commercial-intelligence, and integration** opportunities — where the most *durable* moats form.

## 21.2 The strategic insight
Pharma's biggest *durable* moats are **proprietary data networks** built by aggregating fragmented, trapped data (export registrations, tenders, channel sell-out, vendor qualification, patent/expiry). Each is a **services/SaaS wedge today → data network tomorrow**. Data networks compound and resist copying.

## 21.3 Money & power
Whoever owns recent, structured, trusted data sells intelligence at high margin (IQVIA, AIOCD model). Power: incumbents in commercial data; **whitespace** in export/tender/channel/vendor/regulatory data.

## 21.4 Manual workflows & pain
Manual portal-scraping; Excel aggregation; no single source of truth; data-quality and entity-resolution problems; integration absent.

## 21.5 Opportunity harvest
- **🟢 Data networks:** export-registration network (OPP-01), tender network (OPP-03), vendor-qualification registry (OPP-16), channel sell-out (OPP-15), patent-cliff (OPP-20).
- **🟢 Integration:** mid-market data fabric (OPP-29).
- **🟢 Commercial intelligence:** affordable alternative/complement to IQVIA for mid-market.
