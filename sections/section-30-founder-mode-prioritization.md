## 30.2 The three wedge candidates (pick 1, design for the platform)
**Wedge A — Export Regulatory Lifecycle (OPP-02→OPP-01).** *Best overall fit.* Start as **managed RA + renewal/variation tracking** for 10–20 mid-market exporters (immediate, painful, sticky) → accumulate registration/renewal/competitor data → release **lifecycle SaaS + export intelligence** → expand to tender (OPP-03), distributor discovery (OPP-26), patent-cliff (OPP-20), and **export-receivable finance** (OPP-12). *This is the lifetime platform.*

**Wedge B — Pharma Compliance Platform (OPP-08→OPP-10).** Start as **managed audit-readiness** → continuous managed compliance → **eQMS + AI compliance** → supplier registry (OPP-16) → compliance-linked credit scoring (OPP-31). Strong if you prefer the manufacturing-side buyer.

**Wedge C — Commercial/Channel Intelligence→Fintech (OPP-03/OPP-15→OPP-04).** Start as **tender + channel intelligence** → channel visibility → **channel working-capital finance**. Best if you want the fintech flywheel earliest (needs a capital partner sooner).

> **Recommendation:** **Wedge A.** It maximizes founder fit (finance/compliance/AI/SaaS), starts permissionless and asset-light (C2, T2), builds the most defensible asset (a regulatory/export **data network**), and has the clearest path to a **lifetime compliance→data→fintech platform**.

## 30.3 The lifetime platform thesis (one sentence)
> Build the **operating system for Indian pharma exporters and mid-market manufacturers** — beginning with regulatory/export compliance, compounding into proprietary regulatory/export/channel/vendor **data networks**, and culminating in **pharma fintech and traceability infrastructure**.

## 30.4 90-day validation plan
**Weeks 1–3 — Customer discovery (no build).** 20–30 interviews: mid-market export/RA heads (target), CFOs, distributors, QA heads (blocker). Use question banks from `frameworks/04` + each section. Validate: renewal-miss pain, agent spend, WTP, switching barriers, QA/validation gates.
**Weeks 4–6 — Wedge definition.** Pick the sharpest first job (likely **renewal/variation tracking + managed RA**). Define ROI vs. cost of a missed renewal. Price (retainer + per-market).
**Weeks 7–10 — Sell before build.** Sign 3–5 paid design partners (LOIs/advances) for managed RA. Begin services delivery manually (the beachhead). Start capturing structured data from day one (the future moat).
**Weeks 11–13 — Productize v1.** Ship the renewal/variation tracker SaaS to design partners. Define the data schema for the export data network. Decide next module (tender vs. patent-cliff).

## 30.5 Hire/partner plan
- **Hire:** senior RA specialist (multi-market), 1–2 RA associates, 1 full-stack + 1 data engineer.
- **Partner:** country agents (for in-market filing), later an **NBFC** (for OPP-12 export finance).
- **Advisors:** ex-RA head of a mid-size exporter; a Pharmexcil-network connector.

## 30.6 Capital & milestones
- **Seed (C2, <₹5cr):** services + v1 SaaS + data schema. **Milestone:** 5 paying customers, renewal-tracking live, data pipeline running.
- **Series A:** multi-module platform + data network + first intelligence subscriptions. **Milestone:** ARR + NRR proof, 50+ customers.
- **Expansion:** tender/patent-cliff/distributor modules → **export finance** (capital partner). **Milestone:** financing book + data-driven underwriting.

## 30.7 Reasons this could fail (and mitigations)
- *Data acquisition hard* → start with data customers generate themselves (their own registrations) before aggregating market-wide.
- *Agents resist disintermediation* → partner with agents, don't replace them initially.
- *Long sales cycles* → lead with the painful, urgent renewal-miss wedge; sell ROI vs. catastrophic loss.
- *QA/validation gate* → compliance-first, validated, audit-ready from day one.
- *Fintech capital/credit risk* → phase in later, with a partner and proprietary data edge.

## 30.8 Key learnings (program-level)
- Your durable edge = **finance + compliance + AI + SaaS** applied to pharma's **non-science enabling layers**.
- The winning pattern = **services beachhead → proprietary data network → SaaS/AI → fintech/infra**, attached to a regulatory or money-flow chokepoint.
- The single best starting move = **Wedge A (export regulatory lifecycle)**, executed via the 90-day plan above.
